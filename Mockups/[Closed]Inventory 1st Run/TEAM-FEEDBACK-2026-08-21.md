# 2026-08-21 팀 피드백

## 배경

인벤토리 디자인 목업 1차 런을 팀에 공유한 뒤 받은 피드백이다.
이 피드백은 1차 런을 직접 수정하기 위한 확정 작업 목록이 아니라,
2차 런에서 제작할 신규 목업의 디자인 방향을 검토하기 위한 기준으로 사용한다.

## 피드백

- 기어/장비는 접고 펼치기 방식이 더 좋음
- 부착물 슬롯 선택 시 장착이 안 되는 슬롯은 확실히 비활성화(딤) 처리하기
- 부착물 장착 인디케이터가 부착물 슬롯 전체를 가리지 않게 하기
  - 투명 처리하거나 슬롯 옆에 작게 표시하는 방식 등을 고려
- 무기의 세로 배치는 생각보다 디자인적 긴장감이 높음
  - 무기 영역을 대각선식 배치로 바꾸는 레이아웃을 시도
- 아이템 유형 분리를 아이콘으로 표시하기
- 화면 너머 상황이 보일 수 있도록 화면 중앙 영역을 비워두는 구성도 고려
- 일렬식 리스트와 그리드식 리스트 중 어떤 방식이 더 적합한지는 추가 검토

## 다음 단계

각 피드백 항목은 검토 후 개별 지시에 따라 2차 런에 반영한다.
별도의 결정이나 작업 지시가 있기 전에는 특정 1차 런 프로토타입을 기준안으로
선정하거나 목업에 변경을 적용하지 않는다.
