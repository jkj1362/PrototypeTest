# Inventory 2-a asset audit

Date: 2026-08-27

Source: Figma frame 468:1535.

2-a introduces no new local asset files. It reuses the exact shared second-run
item, category, controller, Gear/Outfit, character, oriented weapon, and socket
reference assets in ../assets/.

The three weapon renders use weapon-m16-oriented.png,
weapon-m249-oriented.png, and weapon-p1911-oriented.png.

The original Figma raster assets correspond to these already-audited shared
exports, so temporary Figma download URLs are not retained in the prototype.
Interactive socket markers are generated from the rendered image bounds; the
shared socket SVGs remain provenance references.
