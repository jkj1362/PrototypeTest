# PrototypeTest

Design-source repository for Unreal Engine UMG prototyping.

## Tracked content

- `Mockups/` - HTML prototypes, adjacent implementation specifications, audits,
  and mockup assets.
- `GabrielOperation/` - shared workflow conventions and session handoffs for
  Claude Code, Codex, and other agents.
- `AGENTS.md` and `CLAUDE.md` - automatic entry points into the shared guidance.

The surrounding Unreal project is intentionally kept outside version control in
this repository. Generated Widget Blueprints are build artifacts; the HTML
mockups and their specifications are the design source of truth.

Start with [GabrielOperation/README.md](GabrielOperation/README.md).
